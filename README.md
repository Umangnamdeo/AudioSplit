
# AudioSplit 🎧

> A modern, privacy-focused web application built for audio extraction and multi-track stem separation directly in the browser.

## 🚀 Features

- **MP4 to MP3 Audio Extraction:** Extract high-fidelity audio tracks from video formats (`.mp4`, `.mov`, `.mkv`, `.avi`, `.webm`).
- **Configurable Bitrates:** Export audio tailored to your needs (`128 kbps`, `192 kbps`, `320 kbps`).
- **Multi-Track Stem Separation:** Isolate vocals, instruments, and distinct audio layers.
- **Privacy-First Architecture:** 100% client-side processing—your media never leaves your browser.
- **Responsive UI:** Intuitive drag-and-drop interface with zero setup required.

## 🏃 Getting Started

### Prerequisites

A modern web browser (Chrome, Firefox, Edge, or Safari).




---

## 💡 How It Works

1. Drag and drop your audio or video file into the upload zone.
2. Select your target output settings (bitrate or stem separation).
3. Click process to split or extract, then download your output files.
